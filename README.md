## Methods for gathering data to be used for data analysis

Learning different ways to gather data is important for a data scientist. There are three primary ways you'll end up gathering data.

**3 Ways to Gather data for a Data Scientist**

- ingesting a CSV
- pulling from an API
- data scraping from a website

  **Repository organization**

  - Milestone 1 - Write up on project with overview
  - Milestone 2 - Pull TMDb 5000 Movies dataset (from Kaggle) and initial EDA
  - Milestone 3 - Clean and format website data - connect to Box Office Mojo site and initial EDA
  - Milestone 4 - Connect to API and pull data from OMDb API; you *must* apply for an api key from [OMDbAPI](https://www.omdbapi.com/apikey.aspx)
  - Milestone 5 - Merging data, create visualizations, and storing it in a local sqlite database. Simple SQL to join the data.

___

## How To

- Start with Milestone 1 to see what you are getting yourself into
- Milestone 2 will show you how to pull the TBDb 5000 Movies dataset from Kaggle and includes initial EDA for that dataset
- Milestone 3 will show you how to pull website data by connecting to Box Office Mojo site as well as initial EDA for that data
- Milestone 4 will connect to OMDb API and show you how to pull data from an API
- Milestone 5 will show you how to merge data together from these data sources, store it in a local database, and create visualizations

Pull each milestone.ipynb into Jupyter lab/notebook or Google Colab and run
